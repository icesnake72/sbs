인증/토큰 흐름 컴포넌트

React 인터셉터, 세션 복구, 401 분기 처리의 기준 흐름

1) `POST /api/login`
2) AccessToken 저장
3) API 요청 + Bearer
4) 401 + TOKEN_EXPIRED
5) `POST /api/refresh` 후 재시도
웹: RefreshToken은 HttpOnly 쿠키 요청시 withCredentials 필수 INVALID_TOKEN이면 즉시 로그아웃 
// axios 기본 설정 (요약)
const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || 'http://localhost:9080',
  withCredentials: true
});
